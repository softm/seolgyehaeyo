# 설계한눈 · seolgyehannun

**설계사무소 선택부터 견적 비교·계약·공사 완료까지, 일반 건축주가 확인할 정보와 다음 행동을 안내하는 웹앱.**

설계를 처음 맡기는 사람도 “어디에 맡길지, 누가 담당하는지, 얼마가 더 드는지, 지금 무엇을 해야 하는지”를 이해하도록 돕는 프로젝트입니다.

## 지금 내 상황에서 시작하기

- 설계사무소를 알아보고 있어요
- 견적을 받았어요
- 계약하려고 해요
- 이미 맡겼는데 진행이 걱정돼요
- 공사가 거의 끝났어요

## 계획한 주요 기능

| 기능 | 사용자가 얻을 도움 |
|---|---|
| 사무소 비교 | 맡는 일·비슷한 경험·실제 담당자·상담 방법 확인 |
| 기본 등록 확인 안내 | 공식 조회 경로와 요청할 자료, 확인한 날짜·범위 표시 |
| 견적 비교 | 포함된 비용 / 따로 내는 비용 / 아직 모르는 비용 구분 |
| 계약 준비 | 업무 범위·결과물·지급 조건·변경 기준을 쉬운 질문으로 확인 |
| 진행 안내 | 현재 단계, 기다리는 이유, 다음 행동 1~3개 확인 |
| 변경·완료 관리 | 변경 금액·일정·합의와 최종 자료·남은 보수 기록 |
| 내 프로젝트 | 견적·계약·도면·질문·진행 이력을 저장하고 다시 확인 |

## 제품 원칙

1. 전문용어보다 사용자가 물어볼 질문과 할 일을 먼저 보여줍니다.
2. 정확한 면적·예산을 몰라도 시작하고, “아직 모르겠어요”를 지원합니다.
3. 공식 확인, 업체 설명, 사용자 입력, AI 추출, 미확인 내용을 구분합니다.
4. 확인되지 않은 비용은 0원으로 합산하지 않습니다.
5. 등록 확인과 업무 품질을 구분하고, 근거 없는 사기 판정·안전점수를 만들지 않습니다.
6. 프로젝트 문서는 기본 비공개로 설계하고, 공개 업체 정보와 분리합니다.
7. 저장 완료는 서버 반영과 재접속 후 복구가 확인된 상태를 뜻합니다.
