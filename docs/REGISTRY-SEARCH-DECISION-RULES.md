# 공식 등록업체 검색 판정 기준

## 목적
의뢰자가 건축설계·측량 등 실제 의뢰 업무를 수행할 자격이 있는 업체인지 공식 등록정보로 확인한다.

## 판정
- 공식 등록대장에서 동일 등록번호 및 업체 식별정보가 일치하고, 업무 종류가 적합하며, 기준일과 유효 상태를 확인한 경우: `등록 확인`.
- 검색 결과가 없거나 일치 여부가 불명확한 경우: `등록 확인되지 않음 — 계약 전 관할 등록기관 확인 필요`.
- 공식 폐업·등록취소·업무정지 자료에서 명확히 확인되는 경우: 해당 사실 및 적용 기간을 근거와 함께 별도 표시.
- 명단 부재만으로 `무허가 업체`라고 단정하지 않는다. 자료의 누락·갱신 지연·상호 변경·관할 및 업종 차이가 있을 수 있다.

## 검색 원칙
1. 업무 유형을 건축사사무소/측량업/기타 인허가 대행으로 먼저 구분한다. 공간정보산업협회 조회는 측량업 등록 확인에 활용하고 건축사사무소 등록의 대체 근거로 사용하지 않는다.
2. 공식 협회 조회 및 관할 지자체 등록대장(엑셀·CSV)을 연결하고 원본 URL, 게시일, 기준일, 수집일, 파일 해시를 보존한다.
3. 상호명 외에 등록번호, 대표자, 주소, 업종을 대조한다. 동명이인·유사 상호는 자동 확정하지 않는다.
4. 정기적으로 자료를 재수집하고 변경·폐업·처분을 이전 스냅샷과 비교한다. 실패 시 이전 자료를 최신이라고 표시하지 않는다.
5. 조회 결과에 근거 링크, 자료 기준일, 조회 시각, 관할기관 확인 안내를 표시한다.

## UI 상태
`등록 확인` / `등록 확인되지 않음` / `업무범위 불일치` / `공식 처분 확인` / `조회 오류`.

## 미완료 구현
공식 게시판 URL·접근 정책 확인, 실제 수집 커넥터, 스케줄러, 백엔드 검색 API, 화면 연결 및 종단간 검증은 별도 구현·검증이 필요하다.
