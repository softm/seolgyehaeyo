# 설계사무소 선정부터 준공까지 실무 가이드

작성·공식자료 확인일: 2026년 10월 22일

## 먼저 읽기 — 처음 맡기는 사람을 위한 쉬운 안내

일반 사용자가 처음 알고 싶은 것은 여섯 가지다. **어디에 맡기나, 내 일을 해본 곳인가, 누가 책임지나, 얼마가 더 드나, 언제 끝나나, 지금 무엇을 해야 하나.** 이 질문부터 답을 찾고, 필요한 전문 확인은 담당자·기관의 도움을 받는다.

아래의 판단 기준은 상담과 비교를 돕는 제안이며, 특정 업체의 안전이나 업무 품질을 판정한 결과는 아니다.

### A. 지금 내 상황부터 고르기

| 내 상황 | 먼저 할 일 | 준비하면 좋은 것 |
|---|---|---|
| 사무소를 알아보고 있어요 | 어떤 일을 하고 싶은지 한 문장으로 적고 후보에게 같은 내용을 문의 | 주소 또는 대략적인 지역, 하고 싶은 일, 원하는 시기 |
| 견적을 받았어요 | 금액에 포함된 일과 따로 돈이 드는 일을 확인 | 견적서 사진이나 파일 |
| 계약하려고 해요 | 실제 담당자·포함 업무·지급 조건을 문서로 확인 | 견적서, 계약서, 담당자 연락처 |
| 이미 맡겼는데 진행이 걱정돼요 | 지금 누구의 어떤 작업을 기다리는지 확인 | 마지막으로 받은 도면·메시지·접수자료 |
| 공사가 거의 끝났어요 | 공식 완료 절차와 실제 보수·자료 인수를 각각 확인 | 완료 안내, 남은 작업 사진, 인수자료 목록 |

규모나 정확한 예산을 아직 몰라도 상담을 시작할 수 있도록, 서비스에는 ‘아직 모르겠어요’를 둔다. 첫 화면에서 자격증 종류나 법률 용어를 입력하도록 요구하지 않는다.

### B. 좋은 사무소를 찾기 위한 여섯 질문

| 궁금한 점 | 이렇게 물어보세요 | 답변에서 확인할 것 |
|---|---|---|
| 내 일을 해본 곳인가? | “저처럼 이런 일을 맡긴 사례가 있나요?” | 비슷한 용도·규모의 실제 완료 사례, 그 업체가 맡은 부분 |
| 누가 끝까지 담당하나? | “계약 후 제가 직접 연락할 담당자는 누구인가요?” | 이름·연락 방법, 책임 있는 설명을 들을 수 있는 창구 |
| 얼마가 더 드나? | “견적 금액 외에 제가 따로 내야 할 돈이 있나요?” | 포함·별도·아직 모르는 비용을 나눈 설명 |
| 어디까지 맡아주나? | “제가 다른 업체를 따로 구해야 하는 일이 있나요?” | 사무소가 맡는 일과 내가 준비할 일을 구분한 답변 |
| 언제까지 가능한가? | “첫 도면은 언제 받고, 어디에서 오래 걸릴 수 있나요?” | 단계별 예상 날짜, 필요한 자료·협의 조건, 다음 확인일 |
| 바꾸고 싶으면 어떻게 하나? | “중간에 바꾸면 추가 금액과 기간을 먼저 알려주시나요?” | 변경 전에 범위·금액·일정을 설명하고 합의하는 방법 |

‘그 정도는 다 됩니다’라는 답변만으로 결정하지 말고 사례·범위·조건을 더 물어본다. 현장조사 전이라 비용을 확정할 수 없다는 답변은 그 자체로 문제 신호가 아니다. **무엇을 확인하면 금액이나 일정이 정해지는지 설명하는지**를 본다.

### C. 사무소 정보는 이 순서로 보여주기

| 먼저 보여줄 정보 | 이용자가 이해할 수 있는 표현 | 정보 출처 |
|---|---|---|
| 맡는 일 | 주택 설계, 창고, 토지 정리, 증축 등 | 업체 확인 및 실제 사례 |
| 비슷한 경험 | 어떤 지역·규모의 일에서 무엇을 맡았는지 | 업체 제출 사례, 동의받은 확인자료 |
| 연락·방문 | 위치, 연락처, 상담 방법, 상담료 발생 여부 | 공개 연락처와 업체 확인 |
| 실제 담당자 | 상담한 사람과 계약 후 담당자가 누구인지 | 업체 답변·계약 자료 |
| 비용 범위 | 설계비에 들어가는 일, 별도 비용, 미정 항목 | 해당 사업 견적 |
| 진행·소통 | 첫 결과물 예상일, 질문하는 방법, 답변 기준 | 업체와 합의한 일정·연락 방식 |
| 기본 등록 확인 | 어떤 등록을 언제 어떤 자료로 확인했는지 | 공식 조회·제출 증명서·기관 확인 |

지도·포털·업체 홈페이지의 정보는 후보를 찾는 출발점으로 쓰고, 실제 담당 범위와 현재 상태를 다시 확인한다. 후기에서는 연락·추가비 설명·보완 대응 같은 구체적인 경험을 읽되, 후기 수나 별점으로 적법성·품질을 확정하지 않는다. 업체 광고와 확인된 정보를 구분한다.

### D. 견적은 세 칸으로 읽기

**포함된 비용 / 따로 내는 비용 / 아직 확인하지 못한 비용**으로 나눈다. 금액을 아직 받지 못한 항목은 0원으로 계산하지 않는다.

다음은 설명을 위한 가상 예시이며 실제 시세가 아니다.

| 항목 | A 사무소 | B 사무소 |
|---|---:|---:|
| 처음 받은 설계 견적 | 300만 원 | 450만 원 |
| 공사에 필요한 상세도면 | 별도 금액 미정 | 포함이라고 답변 — 납품 범위 확인 |
| 공사 중 변경 대응 | 별도 금액 미정 | 기본 대응 포함이라고 답변 — 횟수·범위 확인 |
| 측량·감리 등 기타 업무 | 필요한 항목과 금액 확인 중 | 필요한 항목과 금액 확인 중 |
| 비교 결과 | 아직 총지출 비교 불가 | 아직 총지출 비교 불가 |

첫 금액만으로 어느 곳이 더 저렴하다고 결론낼 수 없다. 같은 업무 범위로 다시 견적을 받고, 미정 비용이 얼마나 남는지 함께 본다. 근거가 부족한 상태에서 ‘보통 설계비’, ‘평균 준공기간’을 제시하지 않는다.

### E. 준공까지는 매 단계에서 한 가지씩 확인

| 현재 단계 | 사용자가 할 일 | 남겨 둘 것 |
|---|---|---|
| 처음 상담 | 실제 담당자와 맡는 일 확인 | 담당자 이름·연락처 |
| 견적 비교 | 따로 드는 돈과 미정 비용 질문 | 포함·별도·미정 표시가 있는 견적 |
| 계약 전 | 약속한 업무·금액·일정을 확인 | 서명한 계약과 첨부자료 |
| 도면 검토 | 원하는 방·동선·크기·출입 위치가 맞는지 질문 | 내가 확인한 도면 버전·결정사항 |
| 허가 진행 | 접수했는지, 보완할 것이 있는지 질문 | 접수번호·공식 보완·결과 자료 |
| 공사 중 변경 | 추가 금액과 늦어지는 기간을 먼저 확인 | 변경 설명·비용·일정·동의 기록 |
| 마무리 | 남은 작업과 받을 서류를 확인 | 공식 완료자료·보수 목록·최종도면 |

도면의 구조 안전이나 법규 적합성을 일반인이 직접 판정하도록 요구하지 않는다. 사용자는 자신의 요구사항을 확인하고, 전문 검토 결과는 책임 있는 전문가에게 설명받는다. 허가·사용승인·개발행위 준공·감리비 지급 등 법정 사항은 뒤의 상세 안내를 참고한다.

### G. 앱의 정보 접근성 원칙

- 시작 화면은 ‘알아보는 중 / 견적 받음 / 계약 전 / 진행 중 / 마무리’에서 선택하게 한다.
- 주소와 하고 싶은 일만으로 시작하고, ‘모르겠어요’를 지원한다.
- 명함·견적서·안내문은 사진으로 올리도록 하고, 추출한 항목은 원문과 함께 확인한다.
- 첫 화면에는 지금 할 일 1~3개와 바로 사용할 질문을 보여준다.
- 자격·법령·전문서류는 해당 단계에서 필요할 때 설명과 확인 경로를 제공한다.
- ‘확인했어요 / 물어볼 것이 있어요 / 답변을 기다려요 / 전문가 확인이 필요해요’처럼 이유와 행동을 함께 표시한다.
- 상태는 색상과 글자를 함께 사용하고, 전화·공식 페이지 연결을 쉽게 찾을 수 있게 한다.
- 등록 확인, 업체 설명, 사용자 후기, AI 추출을 서로 다른 출처로 표시한다.
- 일반 정보 탐색은 가입 없이 제공하는 방향을 검토하고, 프로젝트 저장·공유에는 계정과 접근 권한을 적용한다.
- 저장된 견적·계약·도면·질문·답변은 프로젝트에서 다시 열 수 있어야 한다.

이 문서의 앱 관련 내용은 기획 기준이며, 실제 데이터 연계나 앱 구현이 완료되었다는 뜻은 아니다.

## 상세 확인용 부록 — 계약·자격·절차를 더 확인해야 할 때

### 기존 실무 가이드의 목적

건축주가 설계사무소의 자격과 실제 수행자를 확인하고, 자신의 사업에 맞는 업체를 선택한 뒤 계약·설계·인허가·공사·준공·인수까지 증빙으로 관리하기 위한 가이드다. 건축설계와 토목·측량이 함께 필요한 경우를 포함한다.

법령에 근거한 사항에는 출처를 표시했다. 비교 배점, 회의 주기, 제출자료 요구, 운영 방식은 분쟁 예방을 위한 실무 제안이다. 개별 사업에 필요한 절차는 소재지·용도·규모·허가조건에 따라 정한다. 특정 업체에 대한 적법성이나 사기 여부를 판단한 문서는 아니다.

핵심 원칙은 다음 여섯 가지다.

1. 업체 이름, 책임 자격자, 등록번호, 계약 당사자와 실제 수행 관계를 함께 확인한다.
2. 견적은 같은 업무 범위와 같은 결과물을 기준으로 비교한다.
3. 설계, 인허가 대행, 감리, 시공, 사용승인 지원의 담당자와 비용을 구분한다.
4. 진행 상황은 설명과 함께 도면·접수증·공문·회의록으로 확인한다.
5. 변경은 도면·금액·일정·행정절차 영향을 확인하고 승인한다.
6. 행정상 준공과 실제 인수·보수·자료 인도·정산을 각각 확인한다.

## 1. 먼저 맡길 업무의 종류를 구분한다

| 맡기는 업무 | 확인할 담당자·자격 체계 | 계약에서 정할 결과물 |
|---|---|---|
| 건축물 신축·증축·대수선 등의 설계 | 해당 업무를 수행할 수 있는 건축사와 사무소. 법정 예외는 별도 확인 | 배치·평면·입면·단면, 필요한 구조·설비 도서, 인허가 제출본, 실시설계도서 |
| 개발행위·토지조성·토목설계 | 업무 내용에 맞는 등록·기술인력 및 실제 수행업체 | 절·성토, 배수, 옹벽, 진입로 계획, 각종 산출서, 허가·준공 관련 도서 |
| 일반 현황측량·조사측량 | 해당 업종의 측량업 등록과 기술인력 | 현황도, 측량 성과, 설계에 필요한 조사자료 등 약정한 자료 |
| 경계복원·분할 등 지적측량 | LX 또는 법정 업무 범위에 해당하는 지적측량수행자 | 해당 종목의 공식 측량 결과 |
| 공사감리 | 해당 건축물의 법정 감리자 및 지정 방식 | 감리계약, 보고서, 주요 공정 확인·시정 관련 기록 |
| 시공 | 해당 공사를 수행할 수 있는 시공자 | 공사계약·내역서·공정표, 시공 품질 자료, 인수·하자보수 자료 |

건축허가·신고 대상의 건축설계는 원칙적으로 건축사의 업무이며 법정 예외가 있다. 건축사사무소개설신고와 측량업 등록은 다른 제도다. 일반측량업의 범위에도 설계에 수반되는 조사측량 및 인허가 관련 측량도면 등이 포함되므로, 사무소 간판만 보고 어느 법의 어떤 자격이 필요한지 판단하지 않는다. [S1] [S2] [S6] [S7]

경계복원측량은 지적공부상 경계를 현장에 표시하는 것이고, 지적현황측량은 시설물 위치 등을 토지 경계와 대비해 표시하는 것이다. 일반 현황도나 지도 앱의 선을 공식 지적경계 확인 결과로 취급하지 않는다. [S8]

**한 업체가 일괄 창구를 맡더라도 분야별 실제 수행자와 책임 관계를 별지에 적는다.**

## 2. 계약 전에 받을 자료와 확인 순서

| 확인 대상 | 받을 자료·확인 내용 | 주의할 점 |
|---|---|---|
| 책임 건축사 | 성명, 등록번호, 유효한 건축사자격등록증 | 시험 합격 자격증과 현재 업무를 위한 자격등록을 구분 |
| 사무소 개설 | 건축사사무소개설 신고확인증 | 사무소명·주소·대표자·신고번호를 계약서와 대조 |
| 계약 상대방 | 사업자등록증, 개인·법인 구분, 서명권한 | 사업자등록증만으로 전문자격이 확인되지는 않음 |
| 현재 상태 | 최근 행정처분 조회서, 필요 시 관할 신고·관리기관 문의 | 과거 자료의 진위와 현재 영업·업무 상태는 별도 |
| 실제 책임 구조 | 책임 건축사, 실무 담당자, 외부 협력업체 목록 | 누가 상담·작성·검토·서명하는지 설명받기 |
| 경험 | 유사한 사업 완료 사례, 실제 담당 범위, 가능한 실적증명 | 다른 회사에서 수행한 경력인지, 현 사무소 실적인지 구분 |
| 대금 수령 | 계약 당사자와 계좌 명의·수령권한, 증빙 발행 방식 | 개인사업자는 대표자 명의 계좌일 수 있음. 명의만으로 불법 단정 금지 |
| 배상 수단 | 해당 업무에 적용되는 보험·공제 증빙과 보장 범위 | 가입 여부뿐 아니라 적용 사업·기간·한도·면책 확인 |
| 측량·토목 협력 | 실제 업체의 등록증·업종·등록번호, 담당 기술인력 | 소개한 회사와 현장 수행 회사가 다르면 관계를 문서로 확인 |

건축사법은 자격등록과 사무소개설신고를 규정하고 있으며, 현재 시행 중인 제10조는 건축사의 성명·자격증뿐 아니라 사무소 명칭의 대여도 금지한다. 측량업도 등록증·성명·상호 등을 빌려 업무하는 행위가 금지된다. [S2] [S3] [S9]

직원이나 건축사보가 상담·도면 작성을 보조한다는 이유만으로 명의대여라고 판단할 수는 없다. 확인할 것은 책임 건축사가 실제로 검토하고 설명하며 책임지는 구조인지다. [S2]

### 공식 확인 경로

| 확인할 것 | 공식 경로 | 사용 방법·한계 |
|---|---|---|
| 건축사명·사무소명 | [대한건축사협회](https://www.kira.or.kr/index.do) | 메인에서 건축사·사무소명 검색. 조회 실패만으로 무자격 확정 불가 |
| 자격등록증 진위 | [건축사등록원 증명발급확인](https://kirakarb.kira.or.kr/issue/prfIsnCnfm.do) | 증명서의 발급번호로 진위 확인 |
| 행정처분·설계 실적 자료 | [대한건축사협회 증명서 안내](https://cert.kira.or.kr/certificate_type.do) | 후보 건축사에게 최근 발급본 제출 요청. 누구나 이름만으로 모든 이력을 열람하는 서비스는 아님 |
| 사무소·측량업 현재 등록 상태 | 제출 증명서의 관할 신고·등록기관 | 등록번호·상호·대표·업종을 제시하여 확인 가능한 범위 문의 |
| 시공사 등록·행정처분 | [KISCON](https://www.kiscon.net/) | 시공업체 확인용. 건축사 자격 확인을 대신하지 않음 |

등록원은 발급번호를 통한 증명서 확인 기능을 제공하고, 협회는 행정처분 조회서와 설계·감리 실적증명서를 안내한다. KISCON의 건설업체 정보조회 기능은 용인시 공식 안내에서도 확인된다. [S4] [S5] [S17]

## 3. 좋은 사무소를 고르는 방법

### 같은 요구서를 세 곳 정도에 보낸다

건축주가 먼저 다음 내용을 한 장으로 적으면 견적 비교의 정확도가 높아진다.

| 공통 요청 항목 | 기록 내용 |
|---|---|
| 대상 | 주소·지번, 토지·기존 건축물 자료 |
| 목적 | 단독주택, 창고, 근린생활시설, 토지조성 등 실제 사용 목적 |
| 규모 | 원하는 면적·층수·주차·외부 공간 |
| 예산 | 공사비만인지, 설계·토목·부담금·인입·부가세 등까지 포함한 총사업비인지 |
| 일정 | 희망 착공·완료 시기, 반드시 맞춰야 하는 사정 |
| 포함 업무 | 측량, 계획·실시설계, 허가, 감리, 변경 지원, 사용승인 지원 |
| 특수 조건 | 경사, 성토·옹벽, 진입로, 농지·산지, 기존 시설, 인접 토지 문제 |
| 견적 방식 | 항목별 포함·별도·제외와 추가비 산정 기준 |

큰 비용을 투입하기 전, 범위와 결과물이 정해진 사전검토 계약을 별도로 맺는 방법도 있다. 다만 사전검토 결과가 행정청의 최종 허가를 보장하는 것은 아니므로 남은 조건과 가정을 함께 받는다.

### 평가표 예시

아래 배점은 공식 인증이나 사기 확률이 아니라 후보의 업무 적합성을 비교하는 실무 예시다. 자격·등록·책임 주체가 확인되지 않은 상태를 높은 평가점수로 상쇄하지 않는다.

| 평가 항목 | 배점 예시 | 좋은 답변·자료의 모습 |
|---|---:|---|
| 유사 용도·규모·대지 경험 | 25 | 비슷한 완료 사례의 실제 담당 범위와 난관을 설명 |
| 설계·인허가·협업 수행계획 | 20 | 필요한 검토, 협력업체, 납품물, 예상 보완을 구체화 |
| 예산·변경 관리 | 20 | 예산 검토 시점, 초과 시 대안, 변경 승인 방법 제시 |
| 소통·일정·가용 인력 | 15 | 책임자 면담, 응답 기준, 정기보고, 대체 담당자 명확 |
| 공사 중 지원·인수 연결 | 10 | 질의 대응, 변경도서, 마지막 서류 및 자료 인계 범위 명확 |
| 견적의 투명성 | 10 | 포함·별도·제외, 부가세, 수수료, 방문비, 추가비 구분 |
| 합계 | 100 | 점수와 함께 근거·미확인 항목 기록 |

추천 확인 방법은 완료 현장 방문, 허가받은 범위에서 이전 건축주의 경험 청취, 개인정보를 가린 견적·도면·변경관리 예시 확인이다. 현장 방문과 연락은 관계자의 동의를 받아 진행한다.

### 첫 면담에서 묻는 열 가지

1. 제 사업의 책임 건축사와 실무 담당자는 누구입니까?
2. 그 책임자가 계약 전 대지 조건·예산·허가 위험을 직접 설명할 수 있습니까?
3. 비슷한 용도·규모·지형의 완료 사례에서 직접 맡은 범위는 무엇입니까?
4. 이 사업에서 가장 먼저 확인해야 할 위험은 무엇입니까?
5. 허가도서와 실시설계도서는 각각 어디까지 제공합니까?
6. 측량·토목·구조·설비·감리는 누가 맡고 어떤 항목이 별도 비용입니까?
7. 공사비가 예산을 넘을 가능성은 언제, 어떤 자료로 알려줍니까?
8. 공사 중 질의·설계 변경·현장 방문·사용승인 지원은 어디까지 포함됩니까?
9. 담당자 변경이나 계약 중단 시 파일·접수자료·진행이력을 어떻게 넘깁니까?
10. 일정 지연과 추가비 발생 시 원인·근거·금액·기간을 어떤 방식으로 합의합니까?

## 4. 계약서에 붙일 업무범위표

국토교통부의 현행 「건축물의 설계표준계약서」는 2019년 12월 31일 시행본이며, 업무 범위·세부사항·대가 지급 방법을 당사자가 협의하는 구조다. 이를 출발점으로 프로젝트별 업무범위표와 성과물 목록을 붙이는 방식을 권한다. [S10]

일부 건축물은 허가권자가 감리자를 지정하므로 설계사무소가 감리까지 맡는다고 미리 가정하지 않는다. 지정감리 여부, 설계자의 공사 중 참여 업무, 별도 현장관리 업무를 각각 확인한다. [S11]

### 계약에서 추가로 정할 내용

| 항목 | 구체적으로 합의할 사항 |
|---|---|
| 책임자·협력업체 | 성명·소속·역할, 변경 시 통보·인계 방식 |

| 설계 변경 | 변경 이유·범위·금액·일정의 사전 합의, 긴급 상황의 통지·사후기록 |
| 오류 보완과 요구 변경 | 설계자 귀책 보완, 건축주 요구 변경, 법령·현장 조건 변경을 구분 |

| 제외 비용 | 부가세, 관청 수수료, 부담금, 측량·조사·인입·시험 등 항목별 정리 |
| 불허·지연·중단 | 원인별 책임, 수행분 정산, 자료 인계, 추가업무 처리 |
| 파일·이용 범위 | PDF와 필요한 DWG/IFC 등 형식, 인도시점, 후임 전문가에게 제공할 수 있는 범위 |
| 위임 | 대상 업무·범위·기간을 적은 위임. 백지 문서·비밀번호 공유 금지 |

편집 가능한 원본 파일이나 저작권이 대금 지급만으로 자동 이전된다고 전제하지 않는다. 해당 사업을 완성하고 유지관리하는 데 필요한 파일과 이용 범위를 처음부터 합의한다.

아래는 관리 순서다. 실제 인허가와 설계의 세부 순서는 사업별로 병행하거나 조정할 수 있다.

| 단계 | 할 일 | 다음 단계 전 확인할 증빙 |
|---|---|---|
| 1. 대지·사업성 검토 | 원하는 용도·규모, 도로·경계·배수·지형·각종 규제 검토 | 대지 검토서, 현황 자료, 남은 조사·협의, 총사업비 가정 |
| 2. 사무소 비교·선정 | 자격·등록·실적·책임자·견적 비교 | 확인 자료, 동일 기준 견적표, 미확인 항목 해소 |
| 3. 계약 | 범위·일정·대금·변경·중단·인계 합의 | 서명한 계약서, 범위표, 납품 목록, 지급표 |
| 4. 계획 확정 | 배치·평면·규모·주요 사양·예산 결정 | 버전번호가 있는 승인도면, 결정사항·미결사항 |
| 5. 인허가 | 접수·보완·협의·조건 확인 | 접수번호, 공식 보완 문서, 허가서/신고 처리자료, 모든 조건 |
| 6. 실시설계·견적 | 시공에 필요한 도서와 사양 확정, 동일 도서로 견적 비교 | 실시설계 목록·도서, 내역·규격·제외 항목, 질의회신 |
| 7. 착공 준비 | 시공·감리 계약, 공정·검측·보고 계획, 착공신고 | 시공자·감리자 확인, 계약, 착공 가능 상태의 공식 확인 |
| 8. 공사·변경 관리 | 주요 공정 확인, 질의 회신, 변경 승인·행정처리 | 사진, 검측·보고, 변경 전후 도면·금액·일정·승인 |
| 9. 행정상 완료 | 사용승인·개발행위준공 등 해당 절차 진행 | 감리완료·공사완료도서 등 해당 자료, 공식 승인·검사 결과 |
| 10. 실제 인수·정산 | 시운전·잔여 공사·보수·서류·비용 확인 | 인수 목록, 미완료·하자 목록, 보수기한, 최종도서, 정산표 |

허가와 착공신고는 별도 절차이며, 착공 전에 해당 신고·계약·조건이 갖추어졌는지 확인한다. 건축법 제21조가 착공신고를 규정한다. [S12]

허가 진행 완료와 시공 가능한 설계도서 납품은 관리상 별도로 확인한다. 공사가 시작된 뒤 자재·규격·상세를 결정해야 하는 항목이 많으면 견적 비교와 변경비 관리가 어려워질 수 있으므로 미결정 항목을 명시한다.

## 6. 토지·농지·경사지 사업의 추가 확인

토지조성만 진행하는 사업은 건축물 사용승인 대신 해당 개발행위 준공 등이 최종 절차가 될 수 있다. 건축을 함께 진행하면 관련 절차의 의제·협의 여부를 확인한다. 사용승인 하나로 모든 관련 허가의 후속 절차가 자동 정리됐다고 추정하지 않는다. [S13] [S14]

| 확인 항목 | 받아 둘 내용 |
|---|---|
| 토지 경계 | 필요한 지적측량 종목·결과, 설계 현황도와의 연결 |
| 측량 책임 | 실제 측량업체·담당자·날짜·등록 업종·성과물의 작성·검토 주체 |
| 면적·경사도 | 적용 기준, 원자료의 종류, 산출방법, 수정 이유와 전후 비교 |
| 절·성토·옹벽 | 승인도면의 높이·위치·범위와 시공 중 변경 여부 |
| 배수·우수 처리 | 배수 방향·방류 지점·인접 토지 영향, 필요한 협의 |
| 진입로 | 접도 조건과 사용권 확보 필요 사항, 소유·관리 주체와 협의 |
| 농지·산지 | 전용·일시사용 등 해당 절차의 필요 여부, 부담금·복구 등 조건 |
| 허가조건 | 담당부서, 이행 담당자, 제출자료, 기한, 최종 확인 결과 |
| 준공 범위 | 최신 승인 도면·면적·시설과 실제 시공 결과의 대조 |

측량·경사도·면적 자료를 고쳤다면 무엇을 왜 고쳤는지 설명과 버전이 남아야 한다. 관청 제출본도 건축주가 보관하고, 실제 측정·산출 근거 없는 수치 변경을 요구하지 않는다.

## 7. 대금은 약정한 성과물과 연결한다

설계비, 감리비, 공사비의 지급표를 따로 만든다. 아래는 지급 관리 방식의 예시이며 고정 지급비율을 제시한 것이 아니다.

| 지급 단계 예시 | 확인할 성과물·조건 |
|---|---|
| 계약금 | 계약 성립, 상대방·범위·계좌·지급조건 확인 |
| 계획설계분 | 합의한 계획도면·검토 결과·건축주 결정사항 |
| 인허가 업무분 | 계약에 정한 접수·보완·결과 단계와 증빙 |
| 실시설계분 | 약정 도면·사양·계산·내역 등 납품 및 검토·보완 |
| 공사 중 지원분 | 실제 약정한 질의·변경·방문·보고 업무 |
| 최종 지원분 | 계약상 최종 성과물·신청 지원·자료 인계 등 약정 완료 조건 |

관청 심사나 건축주 사정으로 공사가 지연될 때 이미 완료된 설계업무의 대금을 어떻게 처리할지도 합의한다. 모든 책임을 설계자에게 전가하는 조건은 실제 분쟁 해결에 도움이 되지 않는다.

**감리비는 특별히 구분한다.** 건축법 제25조제11항은 사용승인 신청 때 감리계약에 따른 비용 지급과 허가권자의 지급 여부 확인을 규정한다. 따라서 설계·감리·시공의 모든 잔금을 무조건 사용승인 후에 지급하는 방식으로 통일하지 않는다. [S11]

새로운 추가 업무나 추가비는 범위와 근거를 확인한 뒤 합의한다. 이미 지급기일이 도래한 계약대금의 일방적 지급 거절이나 계약 해지는 별도 문제이므로 계약과 사실관계를 확인하고 처리한다.

## 8. 공사 중 변경과 소통 방식

### 변경요청서에 적을 항목

| 항목 | 작성 내용 |
|---|---|
| 변경 식별 | 변경번호, 요청일, 요청자, 관련 도면 버전 |
| 이유 | 건축주 요구, 설계 보완, 현장 조건, 관청 요구 등 |
| 내용 | 변경 전·후 도면과 사양, 관련 공종 |
| 비용 | 설계비·시공비·기타비 증감을 분리, 부가세 포함 여부 |
| 일정 | 추가 검토·자재 수급·시공에 따른 기간 영향 |
| 검토 | 구조·설비·안전·다른 공종 및 인허가 영향 |
| 승인 | 책임자의 검토, 건축주 확인, 시공 지시와 처리 상태 |

건축법상 변경허가·변경신고가 필요한 변경은 원칙적으로 변경 전에 처리하며, 경미한 사항이나 사용승인 때 일괄신고 가능한 경우는 법정 예외를 확인해야 한다. 현장에서 모두 “나중에 정리”하기로 합의했다고 행정절차가 생략되지는 않는다. [S15]

실무 운영 예시는 주 1회 진행 요약, 중요한 공정 전 확인, 의사결정 후 회의록 공유다. 회의록에는 결정사항·미결사항·담당자·기한을 남긴다. 응답 기한과 보고 빈도는 업무 규모와 계약 범위에 맞춰 정한다.

구조체·배관·방수처럼 나중에 가려지는 부분은 담당 감리자와 필요한 검측·시험·사진 기록 시점을 미리 정한다. 감리가 항상 상주하는 것으로 가정하지 말고 해당 현장의 감리 형태와 방문·보고 방식을 확인한다.

## 9. 의심 신호가 보이면 무엇을 확인할까

| 상황 | 우선 확인할 행동 |
|---|---|
| 책임 자격자를 끝까지 만나거나 연락할 수 없음 | 계약 전 직접 면담과 책임 확인 요청 |
| 계약서·도면·등록증의 이름이 다름 | 위임·소속·협력 관계와 서명권한을 문서로 확인 |
| “다른 사무소에서 도장만 받는다”는 설명 | 실제 설계·검토·책임 구조를 확인하고 감독기관에 문의 |
| 백지 위임장·서명·인감 또는 인증 비밀번호 요구 | 대상 업무가 적힌 위임 방식으로 바꾸고 비밀번호를 전달하지 않음 |
| “허가와 준공은 무조건 된다”는 말만 반복 | 검토 근거, 남은 조건, 실패·보완 시 처리 기준 요청 |
| 견적이 매우 낮지만 포함 범위가 없음 | 누락된 업무·도면·방문·신청·부가세를 항목별 확인 |
| 진행됐다고 하지만 접수번호·공문을 주지 않음 | 공식 접수·보완·결과 자료 요청, 필요 시 건축주 본인 확인 |
| 타인 계좌 입금이나 현금만 요구하며 증빙을 거부 | 수령권한·계약 관계·영수 처리 확인 후 진행 |
| 추가비가 계속 생기나 변경 근거가 없음 | 변경 내역·발생 원인·계약상 산정 근거·승인 이력 대조 |
| 자료 인도를 미루며 담당자·업체를 바꿈 | 약정 성과물·인도기한을 서면으로 요구하고 인계계획 확인 |

이 항목들은 추가 확인 신호다. 사무소가 작거나 후기가 적거나 개인사업자 계좌를 쓴다는 이유만으로 사기라고 판단하지 않는다. 정식 협력업체나 직원의 실무 참여도 적법한 구조일 수 있다.

## 10. 준공·사용승인과 실제 인수를 나누어 완료한다

건축법 제22조는 해당 건축물의 사용승인 절차와 신청서류를 정하고 있으며, 건축물 사용은 원칙적으로 승인 이후다. 법정 예외는 별도 확인한다. 사용승인 확인과 계약상 마감·설비·보수 확인을 별도 항목으로 관리하는 것이 좋다. [S13]

| 완료 영역 | 확인할 자료·행동 |
|---|---|
| 행정 절차 | 사용승인서, 해당 개발행위 준공 결과, 관계 절차의 의제·협의 처리 여부 |
| 최종 설계·시공 자료 | 최종도면, 승인된 변경 반영, 설계·감리·측량 성과물 중 계약상 인도 대상 |
| 설비 인수 | 전기·급배수·환기·냉난방 등 해당 설비 시운전, 설명서, 관리 방법 |
| 미완료·하자 | 위치·사진·조치 담당자·보수기한을 적은 목록 |
| 정산 | 원계약, 승인 변경, 실제 지급, 잔여 지급의 대조 |
| 보증·연락처 | 계약상 하자보증 자료, 시공·설비 담당자 연락처, 보수 요청 방법 |
| 자료 접근 | 모든 원본·최종본을 건축주 계정에서도 열 수 있는지, 백업 확인 |

“최종 서류 인수 완료”와 “보수 완료”는 한 날짜로 합칠 필요가 없다. 남은 항목에 담당자와 기한을 붙여 닫아 가면 된다.

## 11. 문제가 생겼을 때의 대응 순서

1. **자료 보존:** 계약·견적·입금·청구·도면 버전·회의록·메시지·공문·현장사진의 원본을 모은다.
2. **미이행 목록 작성:** 약정 내용, 현재 상태, 요청한 보완, 기한, 상대 답변을 항목별로 정리한다.
3. **서면 요청:** 필요한 설명·보완·자료 인도와 회신기한을 특정한다. 새 추가업무는 근거와 조건을 합의한 뒤 진행한다.
4. **공식 상태 확인:** 무자격·명의대여 의심은 해당 등록·신고 관리기관에 실제 업무와 증빙을 제시하여 확인한다.
5. **분쟁 유형별 해결:** 대금·해지·손해는 계약과 사실관계를 바탕으로 상담하고, 건축분쟁전문위원회의 관할 대상인지 문의한다. 위조·사기 의심은 별도 법률검토 및 수사기관 신고 필요성을 검토한다.

[건축분쟁전문위원회](https://www.adm.go.kr/)는 일정 건축분쟁의 조정·재정을 다룬다. 모든 건설분쟁이 같은 위원회 관할은 아니므로 접수 전 대상 여부를 확인한다. 국토안전관리원 공식 안내의 대표 문의는 055-771-8448이다. [S16]

| 사무소·견적 비교 | 동일 업무 범위로 포함·별도·제외 비교 | 필수 |
| 계약 범위 검사 | 누락된 납품물·지원 업무·추가비 기준 표시 | 필수 |
| 단계별 체크리스트 | 지금 할 일, 필요한 증빙, 담당자와 기한 | 필수 |
| 파일·버전 관리 | 계약·도면·공문·사진의 원본과 변경 이력 | 필수 |
| 변경·지급 관리 | 승인 전 비용·일정 영향과 지급 전 성과물 확인 | 필수 |
| 완료 자료 묶음 | 최종도면·공식 승인·인수·보수·정산 자료 내보내기 | 필수 |
| 자동 자료 조회 | 실제 제공되는 공공자료 범위 내에서 연결 | 후속 검증 |
| OCR·AI 문서 보조 | 문서 항목 추출·비교·질문 생성, 원문 위치 제시 | 후속 검증 |

### 프로젝트 저장의 완료 기준

| 저장할 것 | 동작 기준 |
|---|---|
| 파일 원본 | 업로드 완료 후 프로젝트 목록과 보관함에서 다시 열림 |
| 진행 상태 | 각 단계의 완료·미완료·보완 상태가 계정에 유지 |
| 변경 기록 | 이전 도면·견적·승인을 덮어쓰지 않고 버전으로 보존 |
| 지급 기록 | 청구·승인·실제 지급과 증빙을 구분 |
| 협업 권한 | 건축주·설계자·감리자 등 허용된 참여자만 접근 |
| 저장 실패 | 저장 중·완료·실패 표시, 실패 시 재시도와 복구 안내 |
| 이탈·재접속 | 페이지를 닫고 다른 기기에서 접속해도 승인된 저장분 복구 |
| 자료 내보내기 | 계약·도면·공문·변경·정산 기록을 묶어 내려받기 |

계약서·서명·계좌·도면·현장자료는 기본 비공개로 관리하고, 업체 공개 정보와 분리한다. OCR에서 읽은 자격번호는 공식 확인이 되기 전까지 확인 완료로 표시하지 않는다.

### 확인 상태 표시

| 구분 | 화면에 표시할 내용 |
|---|---|
| 공식 확인 | 확인 항목·기관·자료·확인 시각 |
| 업체 제출 | 업체가 제출한 자료이며 진위·현재성 확인 여부 |
| 사용자 입력 | 입력값과 확인 필요 사항 |
| AI 추출 | 원문 위치와 사용자 검토 상태 |
| 미확인 | 없는 자료·조회 실패·확인 대기 이유 |

공공데이터가 전국 실시간 자격·처분 조회 API로 제공된다고 가정하면 안 된다. 예를 들어 인천시 건축사사무소 공개 파일은 연간 갱신이며 신고구분·사무소명·주소가 주된 항목이다. 이런 자료는 후보 탐색의 출발점으로 활용하고, 현재 자격·처분·실제 수행은 별도 확인해야 한다. [S18]

데이터 화면에는 **원자료 기준일, 수집 주기, 마지막 성공 수집 시각, 마지막 검증 시각**을 구분하여 강조한다. 자동 수집을 방금 했어도 원자료 자체가 오래되었을 수 있기 때문이다.

앱의 대표 결과는 “안전도 95점”보다 **확인 완료 7개 / 미확인 3개 / 다음 지급 전 필요한 자료 2개**처럼 증빙과 행동을 연결하는 것이 적절하다. 이 숫자는 화면 예시이며 실제 검증 결과가 아니다.

## 13. 바로 사용하는 체크리스트

### 계약 전

- [ ] 맡길 업무가 건축·토목·측량·감리·시공 중 무엇인지 구분했다.
- [ ] 책임 자격자와 사무소의 등록자료를 받았다.
- [ ] 계약 상대방·등록자료·계좌·서명권한을 대조했다.
- [ ] 책임자와 직접 사업 조건·예산·위험을 논의했다.
- [ ] 현재 업무 상태와 필요한 행정처분 자료를 확인했다.
- [ ] 유사 완료 실적에서 직접 담당한 범위를 확인했다.
- [ ] 같은 요구서로 복수 견적을 비교했다.
- [ ] 포함·별도·제외 업무와 추가비 산정법을 정했다.
- [ ] 납품 도면 수준·파일 형식·인계·이용 범위를 합의했다.
- [ ] 일정·지급·변경·중단·정산 조건에 서명했다.

### 설계·착공 전

- [ ] 경계·도로·배수·농지/산지 등 미확정 조건을 확인했다.
- [ ] 승인한 계획도면의 버전과 결정사항을 보관했다.
- [ ] 허가·신고의 공식 결과와 모든 조건을 받았다.
- [ ] 실시설계 납품 목록과 실제 도서를 대조했다.
- [ ] 동일 도서·사양으로 시공 견적을 비교했다.
- [ ] 시공자·감리자와 계약·업무·현장보고 방식을 확인했다.
- [ ] 필요한 착공 절차 완료 상태를 확인했다.

### 공사 중

- [ ] 주요 공정의 검측·사진·보고 시점을 정했다.
- [ ] 변경 때 비용·일정·도면·행정절차 영향을 기록했다.
- [ ] 추가 업무·비용에 대한 승인 기록이 있다.
- [ ] 관청 보완과 설계 질의에 담당자·회신기한이 있다.
- [ ] 단계별 지급에 대응하는 성과물·증빙을 확인했다.
- [ ] 원본 파일과 버전 이력이 건축주에게도 남아 있다.

### 준공·인수

- [ ] 해당 사용승인·준공검사 결과와 연계 처리 범위를 확인했다.
- [ ] 승인된 변경이 반영된 최종도서를 받았다.
- [ ] 설비 시운전·사용법·관리자료를 인수했다.
- [ ] 미완료·하자 목록에 담당자·보수기한이 있다.
- [ ] 원계약·승인 변경·지급내역으로 정산했다.
- [ ] 약정한 보증·연락처·자료를 인수했다.
- [ ] 모든 파일을 다시 열 수 있고 별도 내보내기도 확인했다.
