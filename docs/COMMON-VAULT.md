# 공통 SNS 계정과 암호화 프로젝트 보관소

2026-10-28 소스 구현. 기존 Sites의 project_id·공개 범위·ChatGPT 로그인·D1/R2 소유권을 유지한다. 공통 계정은 프로젝트 기록의 선택적 암호화 백업 전송에 사용하며 기존 계정을 자동 병합하지 않는다.

내 프로젝트를 연 뒤 **내 보관소 → SNS 로그인 → 별도 암호 입력 → 저장본 확인 → 현재 자료 저장**을 사용한다. 복원은 기존 프로젝트를 수정하지 않고 **새 프로젝트 사본**을 만든다. 원본 파일 바이트·기존 다운로드 URL·파일 이력은 전송하지 않는다. 계약·일정·질문 등 프로젝트 JSON만 저장한다.

형식 검증은 기존 projectDataSchema를 그대로 사용한다. 작성 중 폼이나 저장 작업이 있으면 복원을 중단한다. 서버의 기존 소유권·버전 검사를 우회하지 않는다. 사본 생성 이후 응답이 끊기면 새 사본을 열어 결과를 확인하며 기존 자료를 삭제하지 않는다.

공통 모듈의 이용과 개인정보: https://softm.github.io/account/privacy.html

운영 반영에는 중앙 registry의 실제 Sites Origin 반영·Firebase 인증 함수 배포, 기존 Sites 소스 저장소 동기화와 같은 Sites ID로 공식 배포가 필요하다. GitHub 소스 병합·타입 검사는 이 배포를 대신하지 않는다. 현재 로컬 실행 환경이 없어 Sites source helper를 실행하지 못한 상태이므로 이 문서는 운영 완료를 의미하지 않는다.
