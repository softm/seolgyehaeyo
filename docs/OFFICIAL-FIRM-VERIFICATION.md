# 공식 등록업체 검증 — 데이터 수집 및 판정 규칙

## 목적
의뢰자가 건축사사무소·토목/측량업체를 선택할 때 공식 공개명부와 제출 증빙을 대조하도록 돕는다. 명부에 없다는 이유만으로 불법·무면허·사기라고 판정하지 않는다.

## 수집 설계
- 출처 등록부(source_id, 기관, URL, 지역, 업종, 형식, 공표 기준일, 공표 주기, 마지막 성공시각, 마지막 시도시각, 원본 해시, 행수, 실패 사유)를 유지한다.
- 공개 파일의 CSV/XLS/XLSX를 원본 그대로 보관하고 파싱한다. PDF는 별도 검토한다.
- GitHub Actions 매일 오전에 출처 메타데이터를 확인하고, 파일이 바뀌었을 때만 다운로드/검증한다. 주기가 연간인 자료는 매일 새 파일이 생긴다고 가정하지 않는다.
- 행수 급감, 필수 컬럼 누락, 중복 등록번호 급증, 파일 형식 변경은 자동 반영을 중단하고 이전 정상본을 유지한다.
- 원본 기준일, 수집 시각, 앱에 반영한 시각을 별도로 표시한다.
- 표준화 필드: 법적 업종, 등록번호, 상호 원문/정규화, 대표자, 주소 원문/정규화, 전화, 관리기관, 출처, 기준일, 원본 행 식별자.
- 등록번호+업종+관리기관이 일치하면 강한 후보로 연결한다. 등록번호가 없으면 상호+주소+대표자를 비교하되 유사도만으로 동일 업체 확정 금지.
- 이전 명부에 있고 새 명부에 없으면 '최신 공개명부에서 미확인'으로 표시한다. 폐업/말소 확정은 공식 처분자료가 있을 때만.
- 측량업 등록은 건축설계 자격을 증명하지 않으며, 건축사사무소 신고는 지적측량 수행 자격을 증명하지 않는다.

## 사용자 화면
- 공식 명부에서 확인됨 (출처/기준일/일치 항목)
- 현재 상태 추가 확인 필요
- 자료 불일치 (항목별 차이와 확인 질문)
- 검색 결과 없음 (해당 공개자료 범위에서만)
- 공식 제한 확인 (근거 공문/기간 명시)
- '업체에 등록증 요청하기', '관할기관에 확인하기' 질문 복사.
- 등록 확인, 실제 영업 여부, 실제 업무 담당자의 자격/명의대여 위험은 각각 독립 항목.

## 배포 게이트
1. 출처 URL과 파일 다운로드 가능성 검증
2. 이용허락과 재배포 범위 검증
3. 샘플 파서 테스트, 원본 해시 대조
4. 자동 수집 실행 결과와 실패 알림 확인
5. 실제 업체 조회 UI 및 오탐 검증
6. data-status.html에 주기, 마지막 시도·성공, 원본 기준일, 수집 건수, 검증 상태 표시

현재 이 문서는 설계·출처 목록이며 자동 수집·업체 검증 API의 운영 완료를 의미하지 않는다.
