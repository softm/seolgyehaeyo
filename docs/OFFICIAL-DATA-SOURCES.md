# 설계해요 공식 등록업체 검색 — 운영 출처 목록

## 확인된 공식 출처
- 충청북도 측량업체 등록현황: https://www.data.go.kr/dataset/3075673/fileData.do
  - 충청북도(청주시 제외) 관할; 청주시는 별도 관리
  - 일반측량업·공공측량업·지적측량업
  - 공개 파일의 기준일을 반드시 확인하고 검색 결과에 노출
- 공간정보산업협회: https://www.kasm.or.kr/
  - 실제 업체검색 게시판 URL, 조회 이용조건, 자동접근 가능 여부는 추가 검증 필요
- 대한건축사협회: https://www.kira.or.kr/
  - 건축사사무소는 측량업체와 별도 등록 체계

## 연동 절차
1. 공식 파일의 직접 다운로드 URL과 갱신일·이용허락을 확인한다.
2. GitHub Actions에서 허용된 파일만 다운로드해 scripts/registry_ingest.py 로 정규화한다.
3. 원본 해시·출처·기준일을 기록하고 data/registry/*.json 으로 공개한다.
4. 업체명 부분검색과 등록번호 정확검색을 제공한다.
5. 등록번호, 상호, 주소, 업종을 대조한다. 미검색은 '등록 확인되지 않음'으로 표시한다.
6. 수집 실패 시 직전 정상 데이터를 보존하고 최신이라고 표시하지 않는다.

## 배포 제한
직접 파일 URL과 자동 접근 권한이 확인되기 전에는 자동 수집이 된 것처럼 표시하지 않는다.
