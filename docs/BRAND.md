# 설계해요 이름과 제품 관점

- 서비스명: **설계해요**
- 저장소: **seolgyehaeyo**
- 계열: **해요(haeyo)** — 사용자의 선택·진행·완료 보조
- 주 사용자: 설계 업무를 맡기는 **의뢰자**
- 소개: **좋은 설계사무소를 고르고, 맡긴 일이 끝까지 잘 진행되도록.**

## 서비스 정의

설계사무소를 잘 고르고, 맡긴 업무가 약속한 범위·비용·일정에 맞게 진행되고 마무리되도록 의뢰자의 확인·소통·의사결정을 돕습니다. 사무소 선정, 견적·계약, 수행·변경, 준공·자료 인수까지 자신의 프로젝트를 이어서 관리하도록 기획합니다.
